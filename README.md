# Français A0–A2 (v2)

フランス語教材。33セクション、1200以上のフレーズ。
全項目に音声・カタカナ・IPA・英語風の読み・使う場面が付いています。

**公開URL: https://tatsuyuki-morishita.github.io/French_textbook/**

ローカルで見るなら `index.html` をダブルクリック。ビルド不要、通信不要、
インストール不要。

**スマホでオフラインに使う手順**

1. Safari で上の公開URLを開く
2. **共有ボタン → 「ホーム画面に追加」**
3. **ホーム画面のアイコンから開く**（← ここが重要）
4. 緑の「オフラインで使えます」が出るまで待つ（数秒）
5. 以降は機内モードでも動きます

★ 3 を飛ばすと動きません ★
iOS はホーム画面アプリに Safari とは別のストレージを与えるので、
Safari 側でキャッシュしてもアプリ側には引き継がれません。
アイコンから一度オンラインで開いて、アプリ自身にダウンロードさせる必要があります。

保存状況は画面上部のバナーと 設定 →「オフライン利用」で確認できます。
うまくいかないときは 設定 →「再取得」。

| | |
|---|---|
| セクション | 33（A0 → A2+） |
| フレーズ | 1,201 |
| 音声ボタン | 1,608 |
| クイズ問題 | 142 |
| 会話 | 217行 |
| 検索対象 | 1,040項目 |

表示言語は **日本語 / English** を切り替えられます（ヘッダーとサイドバーの JA / EN）。
フランス語そのものは当然変わりません。解説・訳・シチュエーション・クイズ・
文法リファレンスがまるごと入れ替わります。

各フレーズに付くもの:

- **音声** — 通常速度とゆっくり（0.5倍）。単語をタップするとその語だけ再生
- **カタカナ** — 口の形の出発点
- **英語風の読み** — `bohn-ZHOOR` のような、英語のつづり感覚での近似
- **IPA** — 正確な音
- **どんな場面で使う？** — いつ・誰に・どこで
- **文法** — そのフレーズが使っている規則。要約がその場に出て、↗ で全文へ飛べる
- **丁寧度** — フォーマル / ニュートラル / カジュアル
- **発音の注意** — その語に含まれる、日本語話者がつまずく音の解説

## 機能

- **文法リファレンス** — 37項目・9カテゴリ。活用表・規則・例文（音声つき）
- **フラッシュカード** — Leitner 方式の間隔反復。全1,040項目が対象
- **検索** — フランス語・英語・日本語のどれでも横断検索
- **クイズ** — 各セクション末に確認問題
- **進捗** — セクション完了、連続学習日数、正答率
- **設定** — 表示言語、カタカナ / 英語風 / IPA の表示切替、読み上げ速度、テーマ

## 設計

### なぜ作り直したか

v1 は各レッスンを JavaScript のテンプレート文字列に直書きした HTML で持っていました
（557KB）。その結果:

- 日本語がゼロ
- 音声ボタンが33セクション中5つにしかない（§1, 3, 31, 32, 33）
- 発音表記も使用場面の説明も無い

これを手作業で足すと、同じ情報を1000箇所以上に書くことになります。
v2 はデータ構造にして、**発音関係はすべて自動導出**にしました。

### 発音パイプライン

3層構造で、上の層が当たれば下は走りません。

1. **項目ごとの上書き** — データの `ipa:` フィールド
2. **例外辞書** — [`js/lexicon.js`](js/lexicon.js)。つづりが音を裏切る高頻度語
3. **規則エンジン** — [`js/phonetics.js`](js/phonetics.js)。書記素→音素の最長一致走査

実績として **1,105フレーズ中1,049（95%）が規則だけで正しく導出**され、
手書きの上書きが必要だったのは56件でした。

IPA からカタカナと英語風の読みを生成し、
[`js/phonemes.js`](js/phonemes.js) の35音素表（日本語の足がかり・英語の足がかり・
どちらが近いか）と突き合わせて、フレーズごとの発音注意を自動で出しています。

### なぜ例外辞書が要るか

規則だけでは判別できない対立があります。代表例:

- **語末の -ent** — 動詞は無音（`parlent` /paʁl/）、名詞・副詞は発音（`souvent` /suvɑ̃/）。
  つづりからは区別できないので、動詞形を辞書に置いています
- **-ill-** — 通常は /j/（`fille` /fij/）だが `ville` /vil/、`mille` /mil` は /il/
- **語末子音** — 原則無音だが `fils` /fis/、`six` /sis/ は発音

### 文法を「覚えなくていい」ようにする

文法が各セクションの中に埋まっていると、後で出てきたときに思い出せず、
結局すべて暗記する必要が出ます。そこで:

1. **規則は一箇所に** — [`data/grammar.js`](data/grammar.js) に37項目
2. **使っているフレーズから直接飛べる** — カードの「文法」欄に要約が出て、↗ で全文へ

リンクは手作業ではありません。624のフレーズを絞り込んだパターン群と照合して、
そのフレーズが実際に使っている規則だけを自動で拾います（発音エンジンと同じ発想）。
半分のフレーズに当たるような広すぎる規則は、何も教えないので意図的に外しています。

### 2言語のしくみ

セクション本体は日本語のまま。英語は [`data/en/`](data/en) に別ファイルで置き、
[`js/i18n.js`](js/i18n.js) がブロック番号で突き合わせて合流させます。

- 翻訳作業が日本語の原文に触れない（壊すリスクがない）
- 英語が無いセクションは日本語に自動フォールバックする
- 番号ずれは黙って壊れるので `validate_en.js` が形を検査する

音素の解説だけは翻訳ではなく**書き直し**です。同じ音でも足がかりが言語で逆転するため:
`ʒ` は英語話者には既知（measure の s）で日本語話者には難しく、`y` はその逆。

### 項目の書き方

必須は `fr` と `en` だけ。発音関係はすべて導出されます。

```js
{
  fr: 'Bonjour',
  en: 'Hello / Good morning',
  ja: 'こんにちは（朝〜夕方）',
  register: 'neutral',                    // formal | neutral | casual
  ja_when: '朝から夕方まで、誰に対しても…',   // 使う場面（日本語）
  when: 'Say it on entering any shop…',   // 使う場面（英語）
  ipa: 'bɔ̃.ʒuʁ',                         // 任意。規則が外すときだけ
  tip: 'R は喉の奥で。'                     // 任意。自動の音素注意を上書き
}
```

ブロックの型: `phrases` `tiles` `conjugation` `dialogue` `note` `quiz`

## 開発

```bash
node validate.js
```

全33セクションをブラウザと同じ順で読み込み、各フランス語文字列が
IPA・カタカナ・英語風の読みを返すか、クイズの正解番号が範囲内か、
ブロック型が既知かを検査します。

```bash
node validate_en.js
```

英語レイヤーがブロック番号でずれていないかを検査します。
ブロック数・項目数・選択肢数の一致、選択肢の重複、
英語モードで日本語に落ちる箇所の数を報告します。

```bash
node test_g2p.js
```

発音エンジンの回帰テスト（40件）。

### 公開とオフライン

GitHub Pages が `main` ブランチのルートを配信しています。
`main` に push すれば数十秒〜数分で反映されます。

- `/` … この教材（v2）
- `/v1/` … 旧版

オフラインは Service Worker（[`sw.js`](sw.js)）で実現しています。
**`sw.js` は生成物なので直接編集しないでください。**
アセットを変更したら必ず:

```bash
node tools/build-sw.js
```

キャッシュ名に全アセット内容のハッシュが入っているので、
1バイトでも変われば新しいキャッシュが作られ、古い方は activate 時に消えます。

★ iCloud / Files アプリにフォルダを置いても iOS では動きません ★
Safari のプレビューが同階層の `css/` `js/` `data/` を読みに行けないためです。
オフラインで使いたい場合は必ず「ホーム画面に追加」を使ってください。

音声について: 読み上げはブラウザ内蔵の Web Speech API を使っています。
端末にフランス語音声が入っていない場合、英語の声でフランス語を読んで
まったく違う音になるため、その状態を検出して画面上部に警告を出します。
差し替えたくなったら [`js/audio.js`](js/audio.js) だけを直せば済むように
隔離してあります。
